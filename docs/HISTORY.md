# History

Every decision that shaped how Dreamports works, one line each, by the issue that made it, each beside the decisions nearest to it. Agents read `AGENTS.md` on every request, so what only matters when changing that part of the project lives here: search this file for a word before changing how something behaves, rather than reading all of it, and add a line here when a change should outlast its pull request. A new line goes right after the line of the decision nearest to it, never at the end of the file: every open pull request that adds at the end is in conflict with the next one merged, and waits for all its checks again (#2064).

Dreamports is the source code for dreamports.net, a home for enhanced fan ports of classic games. A Dreamport is "the port fans always dreamed of: the game you remember, with the extras you wished it had"; use that wording rather than "dream means fan". The site lists the owner's own Dreamports (for example Sonic Advance Dreamport). Every Dreamport keeps the rules in `docs/STANDARD.md`, whoever makes it (#73).

- Since #1588 `read` and the code map cover every piece of a PlayStation 2 game's code: one table both reads and writes the EE's instructions (`tools/ps2/ee.mjs`), with its multimedia ones, its floating-point unit and vector unit 0's macro mode, and another a vector unit's pairs (`tools/ps2/vu.mjs`), whose upper half shares the first's operations. - Since #1588 the tools build Sony's own EE-GCC 2.9-ee-991111-01, its assembler for the EE and `dvp-as` for the vector units, for `match` on the PlayStation 2 (`tools/ps2/gcc.mjs`), from Sony's GPL source release, natively with clang, and keep the build only if it makes the original compiler's objects to the byte. PlayStation 2 games came from three families of compiler, Sony's EE-GCC, SN Systems' ProDG build of GCC and Metrowerks CodeWarrior, and only the first has its source published: SN's builds exist only as programs for Windows in decompilers' collections, and CodeWarrior isn't free, so neither is used.
- Since #1588 `match` builds a PlayStation 2 game's C with Sony's own driver, compiler and assembler (`tools/ps2/match.mjs`) and compares each function with the program the disc boots.
