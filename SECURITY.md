# Security

Dreamports is a static website: it has no accounts, no logins and no database, and it never asks visitors for files or personal details.

## Reporting a problem

If you find something that could put visitors at risk, such as a link that leads somewhere harmful, a page that runs code it shouldn't, or a leaked credential in this repository, please report it privately:

1. Open the [**Security** tab](https://github.com/NahuelGenchi/dreamports/security) of this repository.
2. Choose **Report a vulnerability** and describe what you found.

Please don't open a public issue for it. Only the owner can see private reports.

## Projects listed on the site

Dreamports links to ports and games that live in their own repositories. Report problems with one of those to that project. Tell us here too if a listed project starts shipping ROMs or game files, so its listing can be removed.
