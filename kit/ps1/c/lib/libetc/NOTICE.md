# Sources

The twins in this folder were written from these sources:

- Xeeynamo/sotn-decomp at 396086f (https://github.com/Xeeynamo/sotn-decomp): `src/main/psxsdk/libetc/` (`pad.c`, `vsync.c`, `intr.c`, `intr_vb.c`, `intr_dma.c` and `vmode.c`), each under the MIT License as its first line says, which each file here keeps, taken as that decompilation writes them, with names of their own for the values it named by where they are in its game, every function's `static` left out so it can be a twin, a typedef for the type `startIntrVSync` gives back, and `startIntrDMA` declared as giving 64 bits, as that project declares it, only where `match` builds the file; and, for `libetc_internal.h`, written here, the layout of Sony's table of callbacks as `include/psxsdk/libetc.h` writes it, and `jmp_buf`'s from `src/main/psxsdk/libapi/libapi_internal.h`, under the MIT License as its first line says. The functions' names and sizes in `library.json` come from its `config/splat.us.main.yaml` and `config/symbols.us.txt`.
- mkst/maspsx at 4ffa8b5 (https://github.com/mkst/maspsx), under the MIT License, whose rules for Sony's assembler `match` builds these files with, carried into JavaScript in `tools/ps1/maspsx.mjs`; and GNU's GCC 2.6.3, with the PlayStation's target header from decompals/old-gcc at 370040a (https://github.com/decompals/old-gcc), built on the contributor's computer and not kept here, as that project builds these files with it.
