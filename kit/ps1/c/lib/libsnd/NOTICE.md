# Sources

Nobody has written this library's functions as twins yet. Their names, and their sizes in the program of the game the source is a decompilation of, come from:

- Xeeynamo/sotn-decomp at 396086f (https://github.com/Xeeynamo/sotn-decomp): `config/splat.us.main.yaml`, which says where each file of `src/main/psxsdk/libsnd/` starts in that program, and `config/symbols.us.txt`, where each function starts, so a function's size is to the next one, or to the end of its file.
