# Sources

The twins in this folder were written by hand from the console's own instructions, as `npm run dp -- read` prints them from a contributor's copy of a game that has them. No source's text is in them.

- pret/agbcc at da598c1 (https://github.com/pret/agbcc): agbcc, the compiler `match` builds these twins with to compare them with a game's bytes, run on the contributor's computer and not kept here.
