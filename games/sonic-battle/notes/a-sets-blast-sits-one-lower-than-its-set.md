# A Set's blast sits one lower than the Set it came from.

About: Special attacks; 0x0800f5bc

Proof: #457; #972

Rouge's Set makes kind 120, which at its frame 7 makes kind 121, and 0x0800f5bc turns both into kind 122, the blast, at the same place. The blast's height is one less than the Set's: with the same height its first picture was a pixel above the original's in #457's recording, which played Rouge, and with one less every frame matches.
