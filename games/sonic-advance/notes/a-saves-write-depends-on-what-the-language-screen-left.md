# A save set in the Dreamport's address before the language screen makes later writes vanish, which moves frames.

About: x-zone-the-moon-beaten; x-zone-the-moon-opens; The course select

Proof: #93; x-zone-the-moon-opens

Writing the flash takes 14 frames only when the save has changed since it was last written. The proof's original gets its values in the character select, after the language screen wrote the save, so every later write in it changes something. With the address's values in the Dreamport's save from power-on, the language screen wrote them, a later write found nothing new, and the Dreamport ran 14 frames ahead from there. So the page sets them as Game Start is pressed.
