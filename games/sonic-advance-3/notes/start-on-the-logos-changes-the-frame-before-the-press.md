# Pressing Start on the logos changes the frame before the press.

About: The SEGA and Sonic Team logos; The title screen; logos; title-screen

Proof: #303; logos; title-screen

Once the Sonic Team logo has been shown, Start leaves for the title screen. With Start held from frame N, the original's frame N - 1 is already the black one before the title, with layer 0 and the sprites gone, the same way the name entry shows early in the note on pressing A on the language screen. So a recording that presses Start there differs from the Dreamport on that one frame, and every frame after it matches, picture and sound, as a trial of presses at several frames showed. Start also has to stop the logos' H-blank copies of layer 2's registers, as the task's destructor does, or the title screen's "3" is drawn with the logos' rotation until the screen sets its own. No recording presses Start there for that reason, since it could not match every frame.
