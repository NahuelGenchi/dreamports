# A new game's save unlocks only Sonic and Tails, so the character select shows Knuckles, Cream and Amy as question marks.

About: The character select; character-select

Proof: #305; character-select

The new game's save sets the unlocked characters to Sonic and Tails (`NEWGAME_CHARACTERS`), and a press of A on a locked one does nothing. The kit's default save for a game with nothing saved unlocks the first four, so the recording's start point sets the new game's, as the original has it when the character select opens after the name entry. Treating Cream as unlocked drew her name sliding in at frame 267 where the original still shows the question marks.
